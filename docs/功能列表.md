# DomainRadar 功能列表

## 域名资产管理

- 多注册商 API 同步（GoDaddy、阿里云、腾讯云、Cloudflare、Namecheap）
- 手动添加/导入域名（CSV/Excel）
- 域名导出
- 标签管理（多对多，支持即时创建）
- 分组管理（单归属，支持即时创建）
- 批量操作（设置标签/分组/删除）
- 按状态/注册商/标签/分组/监控类型过滤
- 域名搜索
- 到期日自动判断过期状态（不信任注册商 API 返回的状态）

## 到期监控与告警

- 到期预警（7天/30天/已过期，三级严重度）
- 健康评分自动计算（0-100）
- 到期日历（年/季度/月视图，悬停详情，点击跳转）
- 可配置告警规则（到期天数阈值 + 严重度）
- 告警静默（标签"不续费/no-renew/muted/ignore"标记后停止所有告警）

## 证书监控

- 多端点 TLS 证书检测
- 证书链完整性验证
- 到期倒计时
- 自动告警（过期/即将过期/检测失败）
- 每 6 小时自动检查

## 邮件安全

- 8 项检测：MX/SPF/DKIM/DMARC/PTR/MTA-STS/TLSRPT/BIMI
- 综合评分（0-100）
- 启用/关闭开关
- 合规告警（缺失记录/MX 变更/MX 不可达）
- 每 30 分钟自动检查

## 服务监控

- 探针类型：TCP/UDP/HTTP/HTTPS
- 详细计时：DNS/TCP/TLS/TTFB/下载/总耗时
- 可配置间隔和超时
- 连续 3 次失败触发 service_down 告警
- 恢复时自动关闭告警并通知
- 绕过容器代理直连目标

## WHOIS 监控

- 每日自动 WHOIS 查询（who-dat）
- 到期日/注册商信息更新
- 到期日变更告警（±1.5 天容差，避免时区误报）

## 通知渠道

- Webhook（钉钉/企业微信/飞书/Slack 自动识别格式）
- CNE 告警平台（自定义 alarmCode/apiKey）
- 测试连通性 + 记录日志
- 投递日志查询（成功/失败/错误原因）
- 启动时自动创建默认 CNE 渠道

## 告警中心

- 告警列表（按严重度/类型过滤）
- 单条/批量确认
- 分页（20/50/100）
- 投递状态追踪
- 右上角铃铛实时未确认计数

## Dashboard

- 全局概览（域名总数/即将过期/活跃告警/健康评分）
- 注册商分布
- 证书/邮件监控统计
- 服务监控可用率

## 用户与权限

- SSO OIDC 单点登录
- 本地用户名密码认证
- 角色：Admin/Operator/Viewer
- 组→角色映射
- 审计日志

## 部署与运维

- Docker Compose 一键部署（GHCR 预构建镜像）
- Caddy 自动 HTTPS（Let's Encrypt）
- GitHub Actions CI/CD 自动构建
- 环境变量配置（本地 HTTP:80 / 线上 HTTPS）
- TZ=Asia/Shanghai 北京时间
- NO_PROXY 内网服务隔离
- network_mode: host 兼容 iptables 异常机器
