# DomainRadar 功能列表

## 域名资产管理

| 功能 | 说明 |
|---|---|
| 多注册商同步 | GoDaddy、阿里云、腾讯云、Cloudflare、Namecheap API 自动拉取 |
| 手动添加 | 表单创建单个域名 |
| 批量导入 | CSV / Excel 文件导入 |
| 域名导出 | 按筛选条件导出 |
| 标签管理 | 多对多，支持即时输入创建 |
| 分组管理 | 单归属，支持即时输入创建 |
| 批量操作 | 批量设置标签 / 分组 / 删除 |
| 多维过滤 | 状态、注册商、标签、分组、监控类型 |
| 域名搜索 | 模糊匹配域名名称 |
| 过期判断 | 根据到期日自动标记 expired，不信任注册商 API 状态 |
| 已取消过滤 | GoDaddy CANCELLED 等无效域名自动排除 |

## 到期监控与告警

| 功能 | 说明 |
|---|---|
| 到期预警 | 7天 / 30天 / 已过期，三级严重度 |
| 健康评分 | 0-100 自动计算，基于到期天数 |
| 到期日历 | 年 / 季度 / 月视图切换，自动定位今天 |
| 日历交互 | 悬停显示详情，点击跳转域名详情 |
| 告警规则 | 可配置到期天数阈值 + 对应严重度 |
| 告警静默 | 标签"不续费 / no-renew / muted / ignore"标记后停止所有告警 |
| 每 6 小时检查 | 自动扫描所有域名更新健康评分和告警 |

## 证书监控

| 功能 | 说明 |
|---|---|
| 多端点检测 | 同一域名可监控多个 TLS 端点 |
| 证书链验证 | 检查证书链完整性 |
| 到期倒计时 | 剩余天数实时显示 |
| 自动告警 | 过期 / 即将过期 / 检测失败 |
| TLS 详情 | 版本、密码套件、SAN、签发者 |
| 连接计时 | DNS / 握手 / 总耗时 |
| 每 6 小时检查 | 周期性自动检测 |

## 邮件安全

| 功能 | 说明 |
|---|---|
| MX 检测 | MX 记录存在性和可达性 |
| SPF 检测 | SPF 记录配置验证 |
| DKIM 检测 | 多选择器 DKIM 签名验证 |
| DMARC 检测 | DMARC 策略配置验证 |
| PTR 检测 | 反向 DNS 解析验证 |
| MTA-STS 检测 | 传输安全策略验证 |
| TLSRPT 检测 | TLS 报告配置验证 |
| BIMI 检测 | 品牌标识验证 |
| 综合评分 | 0-100 加权总分 |
| 启用/关闭 | 每个域名独立开关 |
| 合规告警 | 缺失记录 / MX 变更 / MX 不可达 |
| 每 30 分钟检查 | 周期性自动检测 |

## 服务监控

| 功能 | 说明 |
|---|---|
| TCP 探针 | TCP 端口连通性检测 |
| UDP 探针 | UDP 连通性检测 |
| HTTP 探针 | HTTP 请求 + 状态码验证 |
| HTTPS 探针 | HTTPS 请求 + TLS + 状态码验证 |
| 详细计时 | DNS / TCP / TLS / TTFB / 下载 / 总耗时 |
| 可配置间隔 | 自定义检测频率和超时时间 |
| 宕机告警 | 连续 3 次失败触发 service_down critical |
| 恢复通知 | 恢复时自动关闭告警并推送恢复通知 |
| 直连目标 | 绕过容器代理，Proxy: nil |

## WHOIS 监控

| 功能 | 说明 |
|---|---|
| 每日查询 | 通过 who-dat 服务自动 WHOIS |
| 信息更新 | 到期日 / 注册商自动同步到数据库 |
| 变更告警 | 到期日真正变化时推送通知 |
| 时区容差 | ±1.5 天内差异视为同一日期，避免误报 |

## 通知渠道

| 功能 | 说明 |
|---|---|
| Webhook | 钉钉 / 企业微信 / 飞书 / Slack 自动识别格式 |
| CNE 告警平台 | 对接 cne.verycloud.cn，自定义 alarmCode / apiKey |
| 测试连通性 | 一键测试，结果明确提示成功或失败原因 |
| 投递日志 | 每个渠道独立日志，查看成功 / 失败 / 错误原因 |
| 默认渠道 | 启动时自动创建默认 CNE 渠道（active） |
| 多渠道并行 | 告警触发时所有 active 渠道同时推送 |

## 告警中心

| 功能 | 说明 |
|---|---|
| 告警列表 | 按严重度 / 类型过滤 |
| 单条确认 | 逐条标记已处理 |
| 批量确认 | 勾选多条一键确认 |
| 分页 | 20 / 50 / 100 条切换 |
| 投递状态 | pending / delivered / failed |
| 铃铛计数 | 右上角实时显示未确认告警数 |
| 时间精确 | 精确到秒（北京时间） |

## Dashboard

| 功能 | 说明 |
|---|---|
| 域名总数 | 全量统计 |
| 即将过期 | 30 天内到期数量 |
| 活跃告警 | 未确认告警数 |
| 健康评分 | 全局平均分 |
| 注册商分布 | 按注册商分组统计 |
| 证书监控 | 监控数 / 即将过期数 |
| 邮件监控 | 监控数 / 平均评分 |
| 服务监控 | 可用率统计 |

## 用户与权限

| 功能 | 说明 |
|---|---|
| SSO OIDC | 单点登录（支持 Authentik 等） |
| 本地认证 | 用户名 + 密码登录 |
| 角色 | Admin / Operator / Viewer 三级权限 |
| 组映射 | SSO 组自动映射到角色 |
| 默认管理员 | 首次部署 admin / admin123 |
| 审计日志 | 所有操作记录可追溯 |

## 部署与运维

| 功能 | 说明 |
|---|---|
| 一键部署 | docker-compose.ghcr.yml + .env |
| 预构建镜像 | GHCR 自动构建（backend / caddy / who-dat） |
| 自动 HTTPS | Caddy + Let's Encrypt 证书自动续期 |
| CI/CD | GitHub Actions 推送即构建 |
| 环境适配 | 本地 HTTP:80 / 线上 HTTPS 同一份配置 |
| 时区 | TZ=Asia/Shanghai 全链路北京时间 |
| 代理隔离 | NO_PROXY 排除内网服务 |
| Host 模式 | network_mode: host 兼容 iptables 异常 |
